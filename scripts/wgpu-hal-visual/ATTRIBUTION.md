# Test material

The egui capture harness and generated example PNGs were originally contributed
to [craft-libs#473](https://github.com/storytold/craft-libs/pull/473), commit
`2fb45f3823d9ab253800ea5ffdb1172b456e882e`, under MIT OR Apache-2.0. They are
moved here as a separate regression test. Source and generated examples remain under
the same licence; see the repository's `LICENSE.MIT` and `LICENSE.APACHE`.

No Craft App artwork or font files are included. The text scene uses egui's
existing embedded default font dependency. PNGs are captures of this test's own
window, not user projects or desktop screenshots.
